# 📌 Overview

The **Personal Finance and Budget Assistant** is a menu-driven Java application developed using **Core Java** and **Object-Oriented Programming (OOP)** principles.

This project helps users:

- Track income and expenses
- Manage category-wise budgets
- Generate financial summaries
- Compare budgets with balance/income
- Secure application access using password authentication

---

# ✨ Features

## 🔐 Authentication System
- Password protected login
- Reset password functionality

## 💸 Transaction Management
- Add transactions
- Update transactions
- Delete transactions
- View all transactions

## 📂 Transaction Filters
- View transactions by:
  - Month
  - Category

## 📊 Budget Management
- Add budget limits
- Update budget limits
- Delete budget limits
- View all budgets

## 📈 Financial Insights
- Generate income & expense summaries
- Calculate current balance
- Compare budgets with:
  - Total income
  - Current balance

## ⚠️ Smart Warning System
- Alerts users when balance becomes negative
